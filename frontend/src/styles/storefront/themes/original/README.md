# Original Peditto

Preset original da vitrine, usado pela Gelatto Totosu.

## Arquivos

- `tokens.css`: cores e valores de apresentação específicos do preset.
- `../original.css`: agregador importado junto às skins de loja.

A estrutura visual e os componentes continuam compartilhados em `../../storefront.css`; este preset só define diferenças visuais. Adicione camadas específicas nesta pasta quando forem necessárias, sempre escopadas por `.storefront--original`.
